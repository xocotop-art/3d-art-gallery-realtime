# 3D Realtime Art Gallery

A multi-user interactive art gallery built with React, Three.js (React Three Fiber), and Supabase.

## Features
- Real-time player synchronization
- Multimedia artworks (Images, Videos, GIFs)
- Interactive pop-art cards with information
- Social reactions (Emotes)
- Minimap for navigation
- Responsive 3D environment with premium reflections

## Deployment
Published to GitHub Pages at: https://xocotop-art.github.com/3d-art-gallery-realtime/

## Tech Stack
- React + Vite
- Three.js + React Three Fiber + Drei
- Supabase (Realtime, Database)
- Tailwind CSS
- Zustand (State Management)
- Framer Motion (Animations)
